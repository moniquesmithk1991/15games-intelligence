5. Daily Top 5 selector — historical simulation

For each historical date, rank eligible matches by V4's highest exact-score probability and select at most five. This tests whether selective picks outperform the overall baseline. Matches are ranked using only pre-match predictions. This is NOT a live fixture feed, and cannot guarantee 3/5 wins.

6. Smart Top 5 selector — model agreement + bookmaker checks

Ranks pre-match predictions by Poisson/Dixon-Coles agreement, probability, competition reliability estimated from development data, and optional bookmaker 1X2 odds. Tests several fixed weighting strategies on validation only, then reports evaluation separately. Up to five per day; no forced picks or claimed edge.

Odds checks use only the historical odds columns, if present. Competition reliability is learned from the development period, never from evaluation results. Evaluation is still retrospective because earlier experiments already inspected it.

8. Model and data limitations

  • Current model is an independent-Poisson baseline with competition-specific home/away team attack and defence estimates.
  • Team home and away performance are separated; only earlier match dates in the same competition are used.
  • It does not yet include Dixon–Coles low-score adjustment, injuries, lineups, weather, travel, referee data or bookmaker odds.
  • Historical results alone cannot test odds movement. That requires time-stamped pre-match odds snapshots, not just closing prices.
  • Do not tune settings on the same period used for final evaluation. Keep a later, untouched holdout period for model selection.
  • A high hit rate on a small sample can be misleading. Evaluate calibration, sample size and closing-line value before considering real stakes.
