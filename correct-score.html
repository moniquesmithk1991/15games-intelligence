Data and model information

If The Odds API is unavailable, public OpenFootball schedules from GitHub (and then ESPN) will be used. Scheduled fixtures and kickoff times may be incomplete or approximate. These scheduled games are not verified as listed at any particular bookmaker. Scores are statistical estimates, not fixed results. A 10% correct-score probability means roughly a 90% chance that exact score will not occur. The model uses only completed matches before kickoff, team-specific scoring records, and a Poisson score distribution. Bookmaker prices shown are 1X2 availability, not correct-score odds. Matches with no reliable team match remain visible as “No model” rather than receiving invented probabilities.

Manual fallback if live odds are unavailable

The page automatically calls the existing 15GAMES Cloudflare Worker. If the API has no events or reaches its quota, paste a JSON response from The Odds API (array of events or an object with an events/results array). Never paste an API secret.
